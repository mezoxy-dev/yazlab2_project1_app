# yazlab2_project1_app
Bu proje, Mikroservis Mimarisi ve API Gateway (Dispatcher) yönetimini uçtan uca kurgulamayı amaçlar. Öğrenciler, TDD (Test-Güdümlü Geliştirme) disipliniyle; ölçeklenebilir, güvenli ve bağımsız servisler tasarlayacaktır. Süreç boyunca nesne yönelimli programlama, ağ protokolleri ve servis orkestrasyonu yetkinlikleri ölçülmektedir.
